# session-tag

[English](./README.md) | 日本語

現在のプロジェクトのセッションにタグを付けます。各セッションが何の作業で、どれが完了したかを、判別できるようにします。内容タグは Claude が付けます。完了の印は、手で付けます。

## インストール

```
/plugin install session-tag --marketplace tomoyankun/oziji-claude-plugins
```

スコープの選択、チームでの共有、更新の手順は、[ルートの README](../../README.ja.md) を参照してください。

## 使い方

1. `/session-tag` を入力します。現在のプロジェクトのセッションが、新しい順に(最大100件)ペインに並びます。各行には、更新日時、完了の印、内容タグ、最初のプロンプトの先頭40字が出ます。
2. Claude が、タグのない新しいセッションに、バックグラウンドで内容タグを付けます。1回に最大20件です。作業中は、ペインに `Tagging n/m` が出ます。失敗したセッションはタグなしのまま残り、次にペインを開いたときに再試行されます。
3. 上下の矢印キーで行を選び、Enter を押します。そのセッションに `[done]` が付きます。同じ行でもう一度 Enter を押すと、印が外れます。

現在のセッションには `(current)` が出て、印は付けられません。

## タグの保存先

タグは、mod 専用の保存領域に、セッション ID をキーとして保存します。セッションのファイルは変更しません。ペインを開くとき、ファイルがなくなったセッションのタグを削除します。

タグを付けるたびに、セッションの最初のプロンプト(最大200字)を `haiku` モデルへ送ります。

この mod は、セッションを削除しません。削除には `session-rm` を使ってください。
