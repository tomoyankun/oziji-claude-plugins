# session-rm

[English](./README.md) | 日本語

現在のプロジェクトのセッションを、1件だけ削除します。Claude Code には、セッションを1件だけ削除するコマンドがありません。この mod は、セッションをペインに一覧表示し、選んだ1件を削除します。

## インストール

```
/plugin install session-rm --marketplace tomoyankun/oziji-claude-plugins
```

スコープの選択、チームでの共有、更新の手順は、[ルートの README](../../README.ja.md) を参照してください。

## 使い方

1. `/session-rm` を入力します。現在のプロジェクトのセッションが、新しい順に(最大100件、1ページ8件。一覧の末尾の「Previous page」「Next page」を選ぶ)ペインに並びます。各行には、更新日時と、最初のプロンプトの先頭40字が出ます。
2. 上下の矢印キーで行を選び、Enter を押します。
3. 確認で `Delete` を選びます。残すときは `Cancel` を選びます。
4. 削除すると、ペインが閉じ、削除したセッション ID がトーストに出ます。

## 削除するもの

選んだセッション ID について、`~/.claude` の下の次のパスを削除します。

- `projects/<プロジェクト>/<ID>.jsonl` と `projects/<プロジェクト>/<ID>/`
- `session-env/<ID>`
- `file-history/<ID>`
- `dev-mods/<ID>`(空のときだけ)

削除は元に戻せません。現在のセッションは、一覧に出さず、削除も拒否します。

## 注意

- 削除は `rm -rf` で実行します。`settings.json` の `permissions.deny`(例: `Bash(rm -rf*)`)でも止まりません。コマンドがモデルの Bash ツールを通らないためです。
- 一覧は、最新の100件までです。それより古いセッションは出ません。
- 他の端末で動いているセッションは、確認しません。削除すると、そのセッションの履歴が壊れる可能性があります(未検証)。
- プロンプトが空のとき、ペイン上で `←` キーを押すと、バックグラウンドのセッション一覧に切り替わります。Esc で戻れます。
- `rm` が失敗したときは、ペインとトーストに理由を出します。一部のパスは、すでに削除されている可能性があります。
